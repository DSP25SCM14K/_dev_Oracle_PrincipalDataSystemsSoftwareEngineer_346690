# Dev Kumar — Data Systems Engineering Portfolio

A responsive engineering portfolio featuring an animated multi-model data architecture, performance and schema-evolution story, full experience history, and project links.

Open `index.html` directly or serve this folder with a static web server. GitHub Pages publishes the repository root with the included Actions workflow.

- `index.html` — portfolio content and data systems diagram
- `styles.css` — responsive design and animation
- `script.js` — animated background, rotating focus text, reveals, and project search
